# GLM-5.3 W8A8 Stage B/C Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an isolated GLM-5.3 W8A8 Stage B/Stage C pipeline for Ascend 910B A2 that extracts verifier hidden states with vLLM-Ascend and trains BF16 DSpark B8 or DFlash2 B8/B16 drafters with a 2048-token sliding window.

**Architecture:** Stage B teacher-forces the exact Stage-A token IDs through the deployed ModelSlim W8A8 verifier and stores five post-block streams `[1,20,38,56,75]` plus the post-final-norm LM-head input in BF16. Stage C loads one frozen BF16 target embedding/LM-head artifact and uses an anchor-chunked physical context halo, so neither DSpark nor DFlash2 materializes a dense `A*K x (C+A*K)` mask. The implementation lives only under `glm-5.3-w8/` and reuses stable repository-wide cache/distributed utilities without modifying existing GLM-5.2, Flash, or Omni code.

**Tech Stack:** Python 3.11+, PyTorch/torch-npu, vLLM + vLLM-Ascend, safetensors, Transformers Qwen3 config primitives, pytest.

---

## Fixed experiment contract

- Target: formal `GlmMoeDsaForCausalLM`, 78 base decoder layers, hidden 6144, vocab 154880, untied embedding/head.
- Target runtime: official vLLM-Ascend ModelSlim W8A8 (`--quantization ascend`).
- Hidden layers: logical post-block outputs `[1,20,38,56,75]`; final stream is post-final-RMSNorm and is required by DSpark.
- Cache and target I/O storage dtype: BF16. Stage A and Stage B must use the same W8A8 checkpoint/tokenizer fingerprint.
- Draft backbone: five dense Qwen3-shaped layers, hidden 6144, intermediate 12288, 64 Q heads, 64 KV heads, head_dim 64.
- Both methods: `sliding_window=2048` on every draft layer; context halo is physically gathered per anchor chunk; block-local tokens remain mutually visible.
- DFlash2: physical B8 or B16, dynamic causal convolution, top-16 selector, rank 256.
- DSpark: physical B8 only, Markov rank 256, `0.1 CE + 0.9 TV + 1.0 confidence`, gamma 4, LR 6e-4, three epochs.
- DFlash2: full-vocabulary base CE plus hit-only selector CE, gamma 4/7 for B8/B16, LR 6e-4, three epochs.
